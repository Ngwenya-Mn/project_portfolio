# Milton N. Ngwenya Portfolio

A modern, responsive personal portfolio website showcasing my experience, skills, and projects as a Data Engineer.

## Overview

This portfolio presents my professional profile in a clean, structured, and visually engaging format. It is designed to highlight my background in data engineering, ETL workflows, SQL, Python, Power BI, and data visualization.

## Features

- Responsive layout for desktop, tablet, and mobile.
- Animated hero and section transitions using GSAP.
- Clean, modern UI with a professional visual style.
- Code editor-inspired design elements.
- Clear navigation across portfolio sections.
- Contact-focused call-to-action buttons.

## Purpose

The goal of this portfolio is to present my work clearly to recruiters, collaborators, and potential clients while maintaining a strong personal brand and professional first impression.
